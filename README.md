# SHIFUMI

## Description

A rock-paper-scissors game, developped for a job interview test.

## Features

- SPA
- responsive design ("mobile first") (*in progress*)

## Technologies Used

**Languages**: TypeScript, Sass, HTML<br/>
**Frameworks/Libraries**: React<br/>
**Other Tools**: Git, VSCode, Photoshop

## Libraries Used

* React 18.3
* Typescript 4.9
* Sass 1.77
* Font Awesome 6
* React Responsive 10
